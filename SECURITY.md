# Security Policy

## Supported Versions

`httpds-spark` follows [Semantic Versioning](https://semver.org/). Security fixes are provided for the latest released minor version. Older versions are not patched; please upgrade to the latest release before reporting a vulnerability.

| Version        | Supported          |
| -------------- | ------------------- |
| Latest release | :white_check_mark:  |
| Older releases | :x:                  |

## Reporting a Vulnerability

Please **do not open a public GitHub issue** for security vulnerabilities.

Report vulnerabilities privately using one of the following channels:

- GitHub's [private vulnerability reporting](https://github.com/AmadeusITGroup/httpds-spark/security/advisories/new) feature for this repository, or
- Email **opensource@amadeus.com** with a description of the issue, steps to reproduce, affected version(s), and potential impact.

### What to expect

- **Acknowledgment**: within 3 business days of your report.
- **Initial assessment**: within 10 business days, including a severity evaluation and expected remediation timeline.
- **Resolution**: fixes are prioritized based on severity. Critical issues are addressed as quickly as possible; a coordinated disclosure timeline will be agreed with the reporter.
- **Updates**: security fixes are released as a new patch version and announced via [GitHub Releases](https://github.com/AmadeusITGroup/httpds-spark/releases) and release notes. Where appropriate, a GitHub Security Advisory is published once a fix is available.

## Safe Harbor

We support responsible disclosure and will not pursue legal action against researchers who:

- Make a good-faith effort to avoid privacy violations, data destruction, and service disruption during their research.
- Report vulnerabilities privately and give us reasonable time to remediate before any public disclosure.
- Do not exploit a vulnerability beyond what is necessary to demonstrate it.

## Dependency Vulnerabilities

This repository has GitHub Dependabot alerts and automated security updates enabled. If you discover a vulnerability in a third-party dependency used by this project, please report it through the channels above so we can evaluate impact and coordinate an update.
